# @aibar/protocol

Item Spec v2 types, reverse-URI identifiers, closed predicate DSL, wire
messages, and dependency-free validators. No DOM, no React.

```ts
import { validatePublishBatch, makeItemIdentifier, PROTOCOL_VERSION } from '@aibar/protocol';
```

JSON Schema: `@aibar/protocol/item-spec.schema.json`.

See [architecture](../docs/aibar-architecture.md) §3 and §9.
