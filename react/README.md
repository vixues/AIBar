# @aibar/react

Thin React mount. The kernel owns the plan; React owns one `div`.

```tsx
import { AIBarSurface, createAIBarKernel } from '@aibar/react';
import '@aibar/renderer-dom/styles.css';
```

Peer: `react` `^18 || ^19`. `heightVariable` defaults to off.

[Host guide](../docs/aibar-host-guide.md).
