# Changelog

All notable changes to `@aibar/*` are documented here. Versions are independent
of the LeAgent product version.

## 0.1.0

- Initial extract of the AIBar engine: protocol, core, intent, renderer-dom,
  react, and devtools.
- Host embedding is `AIBarHostAdapter` + definition + item catalog.
- Dual-lane resolver semantics (P1–P6, INV-A7) unchanged from the in-tree engine.
